# 效果预览 / Effect previews

本目录 10 项对比使用 2026-10-11 提供的视频素材，包括美颜总开关、祛痘、大眼、瘦脸、鼻翼、口红、眉毛、美白、腮红、颧骨。MP4 保留原文件，README 直接展示循环 GIF。

转换命令：`python3 tools/convert_comparisons.py --width 360 --fps 15`。GIF 采用 `loop=0` 无限循环，保留完整视频时长。GIF 的 15 FPS 是文档播放帧率，不代表 SDK 处理帧率。

Ten comparison clips supplied on 2026-10-11 are preserved as MP4 and shown inline as infinitely looping GIFs. The GIF playback rate is independent of SDK processing throughput.
